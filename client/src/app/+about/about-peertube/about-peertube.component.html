This platform is powered by PeerTube

PeerTube is a self-hosted ActivityPub-federated video-streaming platform and network using peer-to-peer sharing directly from your Web browser.

It is free and open-source software, under AGPLv3 licence.

For more information, please visit joinpeertube.org.
